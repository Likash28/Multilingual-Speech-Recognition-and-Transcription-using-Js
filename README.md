Real-time speech-to-text in the browser — 82 languages, zero backend, zero cost. Uses the native Web Speech API so there's nothing to install or pay for.

## Demo

Open `index.html` in Chrome → select your language → click the mic → speak.

## Features

- 82 languages supported
- Real-time transcription as you speak
- Download transcription as a `.txt` file
- One-click clear
- Fully client-side — no server, no API keys, no cost
- Responsive UI

## Getting Started

```bash
git clone https://github.com/Likash28/Multilingual-Speech-Recognition-and-Transcription-using-Js.git
cd Multilingual-Speech-Recognition-and-Transcription-using-Js
```

Open `index.html` in Chrome or Edge (Web Speech API is not supported in Firefox).
